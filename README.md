# Hotel Room Booking System – Check-In Module

This repository contains the Check-In module of a Hotel Room Booking System.
The module is developed using C programming and file handling.

## Module Description
The Check-In module records guest details when they arrive at the hotel.
It stores check-in information permanently using file handling.

## Features
- Register guest during check-in
- Store check-in details in a file
- Uses structures and file handling

## Technology Used
- C Programming
- File Handling
